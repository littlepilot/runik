“Why is reading from RAM slow?”

The usual answer

The main reason is the memory hierarchy. The processor reaches data through layers at different distances, and each layer is noticeably slower than the one before it. The closest layer, the L1 cache, sits inside the core and answers in about one nanosecond, but it holds only a few tens of kilobytes.

The L2 cache is a little larger, with an access time of around four nanoseconds. L3 is shared between cores and takes about fifteen nanoseconds. When the data has to come from main memory, RAM, latency climbs to a hundred nanoseconds, roughly a hundred times slower than L1. Reading from an SSD takes microseconds, roughly a hundred thousand times longer than L1.

So for performance, what matters most is keeping frequently used data in the layers close to the processor. Walking an array in order uses cache lines efficiently…
